# Academic personal website

A static, multi-page academic website designed for GitHub Pages.

## Personalize the site

1. Replace `Your Name`, affiliation, email, links, and placeholder text in each HTML file.
2. Add a portrait at `assets/profile.jpg`, then follow the comment in `index.html` to replace the monogram placeholder.
3. Replace `assets/cv-placeholder.txt` with your PDF (for example, `assets/cv.pdf`) and update the CV link.
4. Replace every `href="#"` with the relevant paper, profile, project, or resource URL.

## Publish on GitHub Pages

Push the files to a repository named `<username>.github.io`. In the repository settings, choose **Pages**, then deploy from the root of the default branch.

No build step is required.
